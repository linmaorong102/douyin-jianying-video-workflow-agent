# 加速执行流程

仅当 `SKILL.md` 的“执行模式选择”确认全部关键组件可用时读取并执行本流程。目标是减少 Computer Use 的截图与时间线操作，同时保持剪映音色、预设、音乐和成片参数不变。

## 不可改变的结果

- 口播仍由剪映“解说小帅”以 `1.1x` 生成。
- 标题和字幕仍在剪映中直接使用用户确认的预设；不得在 FFmpeg 中烧录文字替代。
- 背景音乐仍使用剪映收藏中的指定音乐。
- 标题、字幕、口播、背景音乐、主画面和模糊背景以最终口播音频为主时钟，结束误差不超过 1 帧。
- 字幕最终文字只来自原始文案；whisper.cpp 只提供时间依据。
- 第一批验证任务中，模糊背景继续使用已确认的剪映效果。只有 FFmpeg 模糊背景与参考画面通过对比验收后，才允许改由 FFmpeg 生成。

## 组件检查

开始前确认：

1. n8n 可访问，素材入库和文案解析工作流可运行。
2. `ffmpeg` 与 `ffprobe` 可执行。
3. whisper.cpp 程序和中文模型文件存在，并通过模型加载测试。
4. 字幕对齐、SRT 生成、视频预处理和结果验收脚本确实存在且通过测试；不要按设想的文件名调用不存在的脚本。
5. 剪映母版存在，母版版本与当前剪映兼容。
6. Computer Use 能获取并操作当前剪映窗口。

第 4 或第 5 项不满足时，回到兼容模式；第 6 项不满足时停止桌面制作阶段。

## 阶段一：任务生成

1. n8n 扫描新视频并更新素材索引。
2. n8n 解析文案第一段为标题，其余内容为 `narration_text`。
3. 以源文件哈希创建幂等任务，写入素材候选、固定参数和 `等待处理` 状态。
4. Codex 读取实际 `task.json`，不能只依赖聊天记忆。

## 阶段二：剪映生成最终口播

1. 复制经过验证的剪映母版，建立本任务草稿。
2. Computer Use 在剪映中加入完整口播文本，选择“解说小帅”并设置 `1.1x`。
3. 生成并保存完整口播，确认没有截断、重复或空白文本。
4. 使用已验证的方法定位剪映生成的口播音频文件并读取准确时长。
5. 无法可靠定位音频时停止加速模式，不得猜测草稿内部路径或用字符数估算最终时长。
6. 验证成功后把口播路径、时长和 `配音已生成` 写入任务状态。

## 阶段三：生成精确字幕

1. 调用 whisper.cpp 分析最终口播音频，输出包含时间点的结构化识别结果。
2. 使用经过测试的对齐脚本把识别时间映射到原始 `narration_text`。
3. 字幕分段必须满足：每段一行、时间连续、不重叠、不漏首尾、文字和标点完全来自原文。
4. 生成 SRT 后，将所有字幕文字按顺序连接，并与 `narration_text` 做严格相等检查。
5. 严格检查失败时停止，不得把 whisper.cpp 的错字作为最终字幕，也不得人工猜测缺失文字。
6. 保存 SRT、识别原始结果、对齐报告，并把任务状态更新为 `字幕已生成`。

## 阶段四：视频预处理

1. 以最终口播时长为目标时长，使用 FFprobe 读取候选素材时长和编码参数。
2. 使用 FFmpeg 静音、统一为适合剪辑的 H.264 固定 30fps，并保持足够画质。
3. 视频较长时在口播结束点裁剪。
4. 视频短缺不超过 2 秒时，按主 Skill 的规则补齐；短缺超过 2 秒时，从素材库选择内容相关片段补齐。
5. 自动选材只能使用任务中明确允许的素材范围；无法可靠判断内容相关性时交给 Codex 或用户选择，不能随机补片。
6. 第一批验证任务不使用 FFmpeg 替代剪映的模糊背景。FFmpeg 只处理已验证不会改变画面样式的静音、转码、裁剪和拼接。
7. 验证预处理视频无黑帧、无空白段，时长误差不超过 1 帧，再把状态更新为 `视频已处理`。

## 阶段五：剪映快速装配

1. Computer Use 打开任务草稿，导入预处理视频和 SRT。
2. 导入字幕后一次性选择全部字幕，直接点击指定字幕预设并应用到全部；再设置得意黑、字号 10 和坐标 `X = 102`、`Y = -810`。
3. 添加标题，直接点击指定标题预设；再设置得意黑、字号 15 和坐标 `X = 0`、`Y = 854`，标题覆盖全程。
4. 保留或建立与参考一致的模糊背景，无黑边。
5. 原视频保持静音；添加指定收藏音乐，并在口播结束点裁剪。
6. 在同一稳定面板内批量执行操作，阶段完成后再截图验证；不要每个点击都重新截图。
7. 保存草稿并把状态更新为 `等待剪映装配` 或 `草稿已完成`，具体取决于验收是否已执行。

## 阶段六：自动与视觉验收

先运行确定性验收：

- SRT 全文严格等于 `narration_text`。
- 每段字幕无换行，时间不重叠，覆盖首句和末句。
- 视频、口播和可读取的轨道结束误差不超过 1 帧。
- 无黑帧、空白段和源视频声音。

再由 Computer Use 做视觉验收：

- 标题和字幕预设、字体、字号、坐标与参考一致。
- 清晰主画面、模糊背景、标题和字幕没有遮挡或黑边。
- 音色、语速和指定背景音乐正确。
- 时间线没有意外空轨、重复素材或超出口播结尾的片段。

任一项失败时记录失败项并回到对应阶段修正。只有全部通过后才能写入 `草稿已完成`；未经用户明确授权不得导出。

## 性能与回退

- 加速来自复用母版、减少截图、批量界面动作、SRT 一次导入和 FFmpeg 确定性处理，不通过降低验收标准换取速度。
- 某个本地脚本缺失、输出格式不符或验证失败时，只回退该任务到兼容模式；不得删除源素材、原文或已通过的中间结果。
- 剪映版本变化导致母版或坐标失效时停止 Computer Use，重新建立并验证版本配置后再恢复。
